# Gpk releases

Kênh phát hành và cập nhật tự động dành riêng cho **Gpk**.

- Gpk: https://github.com/trgiang1008/gpk-releases/releases/latest
- PingPK: https://github.com/trgiang1008/pingpk-releases/releases/latest

Hai sản phẩm dùng repository, gói cập nhật và LIC riêng. Gpk chỉ nhận `Gpk-vX.Y.Z.zip` từ repository này và xác minh SHA-256 trước khi cài.

Tải ZIP ở Releases, giải nén toàn bộ rồi mở Gpk.exe. Các bản trước 1.0.2 cần tải bản đầu tiên thủ công; từ 1.0.2 chương trình tự kiểm tra cập nhật khi mở và hỏi trước khi nâng cấp.

Không lưu khóa ký, LIC khách hàng, cấu hình nhân vật hay mã nguồn trong repository phát hành.
